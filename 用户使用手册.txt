================================================================================
一、系统简介
================================================================================

公共文化资源管理系统是一个基于AI的综合性文化资源管理平台，为您提供：
- 文化资源的浏览和搜索
- AI智能问答和内容生成
- 图片生成和创作
- 资源上传和分享
- 标注任务管理
- 评分和评论功能

访问地址：http://localhost:5173

================================================================================
二、快速开始
================================================================================

2.1 注册账户
------------
1. 打开系统首页，点击"注册"按钮
2. 填写以下信息：
   - 用户名：至少3个字符，只能包含数字和英文字母
   - 密码：至少6个字符
   - 昵称：可选，不填将自动生成
   - 头像：可选，可以上传自定义头像
   - 安全问题：可选，用于找回密码
3. 点击"注册"完成注册

2.2 登录系统
------------
1. 在登录页面输入用户名和密码
2. 点击"立即登录"
3. 登录成功后自动跳转到首页

默认管理员账户：
- 用户名：admin
- 密码：123456
（首次登录后请立即修改密码）

2.3 忘记密码
------------
如果您忘记了密码：
1. 在登录页面点击"忘记密码"
2. 输入用户名
3. 回答您注册时设置的安全问题
4. 设置新密码
5. 使用新密码登录

三、主要功能使用指南
================================================================================

3.1 首页浏览
------------
功能说明：
- 首页展示3D轮播视频
- 显示文化资源卡片（分页展示）
- 可以查看资源详情

使用方法：
1. 登录后自动进入首页
2. 浏览文化资源卡片
3. 点击资源卡片查看详细信息
4. 使用分页按钮浏览更多资源

3.2 AIGC功能
------------

3.2.1 文字AIGC（智能问答）
---------------------------
功能说明：
- 基于AI的智能问答系统
- 支持上传图片并理解图片内容
- 可以生成传统文化故事
- 支持多轮对话

使用方法：
1. 点击导航栏的"AIGC"菜单
2. 选择"文字AIGC"模式
3. 输入您的问题或提示词（可选）
4. 可以上传图片帮助AI理解（可选）
5. 点击"发送"按钮
6. AI会基于数据库中的文化资源生成回答
7. 如果没有输入文字提示，AI会根据图片内容自动生成传统文化故事

特色功能：
- 支持多轮对话，AI会记住之前的对话内容
- 自动保存对话历史
- 可以创建新会话或加载历史会话
- 支持删除会话（单个、批量、全部）

3.2.2 图片AIGC（图像生成）
---------------------------
功能说明：
- 根据文字描述生成图片
- 支持上传参考图片进行风格迁移
- 可以生成连环画

使用方法：
1. 点击导航栏的"AIGC"菜单
2. 选择"图片AIGC"模式
3. 输入图片描述（可选）
4. 可以上传参考图片（可选）
5. 点击"生成"按钮
6. 如果没有输入文字提示，AI会先生成故事，再根据故事生成连环画
7. 生成的图片会自动保存，可以在历史记录中查看

特色功能：
- 生成的图片质量高，以假乱真
- 支持多种艺术风格
- 自动保存到数据库
- 可以查看生成历史

3.2.3 会话管理
---------------
功能说明：
- 管理您的对话历史
- 支持创建新会话
- 支持加载历史会话
- 支持删除会话

使用方法：
1. 在AIGC页面右侧可以看到历史记录面板
2. 点击"新建会话"创建新对话
3. 点击历史会话标题加载之前的对话
4. 点击"删除"按钮删除单个会话
5. 点击"批量删除"选择多个会话删除
6. 点击"删除全部"清空所有会话
7. 可以点击面板标题栏隐藏/显示历史记录

3.3 图文互搜
------------
功能说明：
- 使用文字搜索相关图片
- 上传图片搜索相关文字内容

使用方法：

文字搜图片：
1. 点击导航栏的"图文互搜"菜单
2. 在搜索框输入关键词
3. 点击"搜索"按钮
4. 查看匹配的图片结果

图片搜文字：
1. 点击"上传图片"按钮
2. 选择要搜索的图片文件
3. 系统自动分析图片内容
4. 显示匹配的文字内容

3.4 资源上传
------------
功能说明：
- 上传文本或图片资源
- 自动查重检测
- 自动创建标注任务

使用方法：
1. 点击导航栏的"资源上传"菜单
2. 选择资源类型（文本或图像）
3. 点击"选择文件"按钮
4. 选择要上传的文件
5. 点击"上传"按钮
6. 等待上传完成
7. 系统会自动创建标注任务

注意事项：
- 文件格式支持：文本文件（.txt等）、图片文件（.jpg, .png等）
- 系统会自动检测重复内容，重复文件无法上传
- 上传的文件会进入审核流程
- 文件命名格式：用户名-日期-时间.扩展名（便于识别和排序）

3.5 标注任务管理
-----------------
功能说明：
- 查看和管理您的标注任务
- 编辑标注内容
- 管理员可以审核标注

使用方法：

查看任务列表：
1. 点击导航栏的"标注任务"菜单
2. 查看任务列表
3. 使用状态筛选器过滤任务（待标注/已标注）

查看标注详情：
1. 在任务列表中点击"查看标注"按钮
2. 查看标注的详细信息
3. 包括实体名称、类型、描述等字段

编辑标注：
1. 在任务列表中点击"编辑标注"按钮
2. 修改标注信息：
   - 实体名称（必填）
   - 实体类型（必填）：人物/作品/事件/地点/其他
   - 描述
   - 来源
   - 时期年代
   - 地理坐标
   - 文化区域
   - 风格特征
   - 文化价值
   - 相关图像链接
   - 数字资源链接
3. 点击"保存标注"按钮

管理员审核（仅管理员）：
1. 管理员可以看到所有用户的标注任务
2. 在已标注的任务中，点击"审核通过"按钮
3. 确认后，标注数据会迁移到正式表
4. 或点击"驳回"按钮，输入驳回原因

3.6 用户设置
-------------
功能说明：
- 修改密码
- 更换头像
- 设置安全问题

使用方法：

修改密码：
1. 点击右上角用户头像，选择"设置"
2. 在"修改密码"标签页
3. 输入旧密码
4. 输入新密码（至少6个字符）
5. 确认新密码
6. 点击"修改密码"按钮

更换头像：
1. 在设置页面的"更换头像"标签页
2. 点击"上传新头像"按钮
3. 选择图片文件
4. 可以拖动和缩放图片调整位置
5. 点击"确认更换"按钮

设置安全问题：
1. 在设置页面的"更换二级问题"标签页
2. 输入自定义安全问题
3. 输入安全问题答案
4. 点击"保存"按钮

================================================================================
四、功能详细说明
================================================================================

4.1 用户角色
------------
系统有两种用户角色：

普通用户：
- 可以浏览所有资源
- 可以上传资源
- 可以查看和管理自己上传资源的标注任务
- 可以使用AIGC功能
- 可以评分和评论

管理员：
- 拥有普通用户的所有权限
- 可以查看所有用户的标注任务
- 可以审核标注（通过或驳回）
- 审核通过后数据会迁移到正式表

4.2 资源类型
------------
系统支持以下资源类型：

文本资源：
- 支持.txt等文本格式
- 系统会自动提取节日名称
- 可以用于标注和检索

图像资源：
- 支持.jpg, .png, .gif, .webp等图片格式
- 系统会自动分析图片内容
- 可以用于图文互搜

4.3 标注字段说明
----------------
标注任务包含以下字段：

必填字段：
- 实体名称：文化实体的名称
- 实体类型：人物/作品/事件/地点/其他

可选字段：
- 描述：实体的详细描述
- 来源：信息来源
- 时期年代：如"唐代"、"明清"等
- 地理坐标：经纬度坐标
- 文化区域：如"华北"、"江南"等
- 风格特征：艺术风格特征
- 文化价值：文化价值说明
- 相关图像链接：相关图片的URL
- 数字资源链接：数字资源的URL

4.4 文件命名规则
----------------
用户上传的文件命名格式：
- 格式：用户名-日期-时间.扩展名
- 示例：admin-2024-01-15-14-30-25.jpg
- 日期格式：YYYY-MM-DD
- 时间格式：HH-MM-SS

优势：
- 文件名包含用户名，便于识别上传者
- 文件名包含日期和时间，便于按时间排序
- 在标注任务中可以直观看到文件信息

4.5 评分和评论
--------------
功能说明：
- 对文化资源进行评分（1-5分）
- 可以发表评论
- 可以回复评论
- 支持多维度评分

使用方法：
1. 在资源详情页面
2. 选择评分（1-5星）
3. 可以输入评论内容
4. 点击"提交"按钮
5. 可以回复其他用户的评论

评分维度：
- 综合评分（overall）
- 内容准确性（accuracy）
- 实用性（usefulness）
- 完整性（completeness）

五、常见问题解答
================================================================================

5.1 登录问题
------------
Q: 忘记密码怎么办？
A: 点击登录页面的"忘记密码"，输入用户名和安全问题答案，可以重置密码。

Q: 登录后显示的用户信息不正确？
A: 可能是浏览器缓存问题。按F12打开开发者工具，在"应用程序"标签的"本地存储"中删除userInfo项，然后刷新页面。

5.2 上传问题
------------
Q: 上传失败，提示"该资源已存在"？
A: 系统会自动检测重复内容，如果文件内容相同（即使文件名不同），也会被识别为重复。请上传不同的文件。

Q: 上传的文件在哪里？
A: 上传的文件存储在uploads/目录，文件名格式为：用户名-日期-时间.扩展名。

5.3 AIGC问题
------------
Q: AIGC生成的内容不准确？
A: AIGC基于数据库中的文化资源生成内容，如果数据库资源较少，可能影响生成质量。可以尝试更具体的提示词。

Q: 图片生成失败？
A: 请检查网络连接和API密钥配置。如果问题持续，请联系管理员。

Q: 如何查看历史对话？
A: 在AIGC页面右侧可以看到历史记录面板，点击会话标题可以加载历史对话。

5.4 标注问题
------------
Q: 看不到标注任务？
A: 普通用户只能看到自己上传资源的标注任务。管理员可以看到所有任务。

Q: 如何编辑标注？
A: 在标注任务列表中，找到状态为"已标注"的任务，点击"编辑标注"按钮。

Q: 标注审核需要多长时间？
A: 标注审核由管理员手动进行，时间取决于管理员的工作安排。

5.5 其他问题
------------
Q: 图片无法显示？
A: 检查网络连接，确认图片文件存在。如果问题持续，请联系管理员。

Q: 页面加载缓慢？
A: 可能是网络问题或服务器负载较高。可以稍后重试。

Q: 如何联系管理员？
A: 如果您是管理员，可以使用admin账户登录。如果是普通用户，请联系系统管理员。

六、操作技巧
================================================================================

6.1 高效使用AIGC
-----------------
1. 提供具体的提示词可以获得更好的生成效果
2. 上传相关图片可以帮助AI更好地理解需求
3. 使用多轮对话可以逐步完善生成内容
4. 定期清理不需要的会话可以保持界面整洁

6.2 标注任务管理
-----------------
1. 填写完整的标注信息可以提高数据质量
2. 使用筛选功能快速找到特定状态的任务
3. 管理员可以批量审核任务，提高效率

6.3 资源上传
-------------
1. 上传前检查文件内容，避免重复上传
2. 使用有意义的文件名，便于后续管理
3. 上传后及时查看标注任务，完善标注信息

6.4 搜索技巧
-------------
1. 使用关键词搜索时，尽量使用准确的文化术语
2. 图文互搜时，上传清晰的图片可以获得更好的搜索结果
3. 结合文字和图片搜索可以找到更全面的资源

七、注意事项
================================================================================

7.1 账户安全
-------------
1. 首次登录后请立即修改默认密码
2. 设置安全问题以便找回密码
3. 不要将账户信息告诉他人
4. 定期修改密码

7.2 内容规范
-------------
1. 上传的内容应符合文化资源主题
2. 不要上传重复或无关内容
3. 标注信息应准确、完整
4. 评论内容应文明、客观

7.3 数据管理
-------------
1. 上传的资源会进入审核流程
2. 只有审核通过的资源才会进入正式库
3. 标注任务需要管理员审核后才能迁移数据
4. 删除操作不可恢复，请谨慎操作

7.4 系统使用
-------------
1. 长时间不操作会自动退出登录
2. 建议定期保存重要数据
3. 遇到问题可以查看系统日志或联系管理员
