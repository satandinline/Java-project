系统简介

公共文化资源管理系统是一个基于AI的智能文化资源管理平台，提供以下核心功能：

- 文化资源浏览：浏览爬取和用户上传的文化资源
- AIGC智能生成：文字和图片AI生成功能
- 图文互搜：图片和文本的相互检索
- 资源上传：用户上传文化资源
- 标注任务：文化资源标注与管理
- 数据统计：管理员数据大屏（仅管理员可见）

快速开始

访问系统

1. 打开浏览器，访问系统地址（默认：http://localhost:5173）
2. 如果未登录，系统会自动跳转到登录页面

默认管理员账号

- 账号：`123456789`
- 密码：`123456`
- 角色：管理员
- 二级问题：我的身份是？
- 二级答案：管理员

默认测试用户账号

- 账号：`987654321`
- 密码：`123456`
- 角色：普通用户
- 二级问题：我的身份是？
- 二级答案：测试用户

⚠️ 重要提示：首次登录后请立即修改默认密码！

用户注册与登录

注册新账号

1. 在登录页面点击"立即注册"
2. 填写以下信息：
   - 密码：至少6个字符（必填）
   - 昵称：可选，不填将随机生成
   - 头像：可选，可上传图片作为头像
   - 安全问题：可选，用于找回密码
3. 点击"立即注册"
4. 重要：系统会自动生成一个8-10位的数字账号，请务必保存好！
   - 账号会以弹窗形式显示
   - 建议截图或记录在安全的地方
   - 账号一旦生成永久不可修改

登录系统

1. 在登录页面输入：
   - 账号：8-10位数字（系统自动生成的账号）
   - 密码：注册时设置的密码
2. 点击"立即登录"
3. 注意：关闭浏览器后需要重新登录（系统使用会话存储，不保存持久登录状态）

忘记密码

1. 在登录页面点击"忘记密码"
2. 输入您的账号
3. 如果设置了安全问题，系统会显示您的问题
4. 输入问题答案
5. 设置新密码

功能使用指南

1. 首页浏览

查看文化资源

- 首页展示文化资源卡片
- 每个资源显示一张代表性图片和描述
- 点击资源卡片可查看详细信息

资源详情页

- 显示资源的完整描述
- 展示该资源的所有相关图片
- 支持图片预览和放大查看

搜索功能

- 在首页搜索框输入关键词
- 支持按节日名称、描述内容搜索

2. AIGC功能

文字AIGC

功能说明：
- 基于RAG技术的智能问答
- 可以回答关于传统文化的问题
- 支持上传图片并理解图片内容
- 如果没有文字提示，会根据图片自动生成传统文化故事

使用方法：
1. 进入"AIGC"页面
2. 选择"文字"模式
3. 输入问题或上传图片（可选）
4. 点击发送，消息立即显示（不等待AI生成）
5. AI回答生成后会自动显示，并显示检索到的相关资源
6. 可以继续对话，系统会记住上下文

特色功能：
- 多轮对话：支持上下文理解
- 图片理解：上传图片后AI会自动分析图片内容
- 故事生成：无提示时自动生成像"夸父逐日"、"嫦娥奔月"这样的传统文化故事
- 即时显示：用户消息发送后立即显示，不等待AI生成
- 检索资源持久化：检索到的资源会持久化显示，支持折叠/展开查看
- 资源详情：点击检索资源名称可查看资源详情（与首页资源卡片一致）

图片AIGC

功能说明：
- 根据文字描述生成图片
- 支持上传参考图片进行风格迁移
- 如果没有文字提示，会先生成故事，再生成连环画

使用方法：
1. 进入"AIGC"页面
2. 选择"图片"模式
3. 输入描述文字或上传参考图片（可选）
4. 点击发送，等待AI生成图片
5. 生成的图片会自动保存

特色功能：
- 连环画生成：无提示时自动生成多张连贯的图片
- 风格迁移：上传参考图片可以提取风格
- 高质量生成：生成的图片以假乱真

会话管理

新建会话：
- 点击"新建对话"按钮
- 开始新的对话主题

历史会话：
- 左侧显示所有历史会话
- 点击会话可加载历史对话
- 支持删除单个、批量或全部会话

会话标题：
- 系统自动提取对话主题作为标题
- 标题不超过20字

3. 图文互搜

功能说明：
- 上传图片，搜索相关的文本资源
- 输入文本，搜索相关的图片资源

使用方法：
1. 进入"图文互搜"页面
2. 选择搜索模式（图片搜文本 或 文本搜图片）
3. 上传图片或输入文本
4. 点击搜索
5. 查看搜索结果

4. 资源上传

功能说明：
- 用户可以上传文本或图片资源
- 文本类型支持直接输入文本内容或上传文件
- 上传的资源会自动创建标注任务，触发AI标注；后台每5分钟自动补偿检查“待标注”任务，防止漏标
- 用户可在上传时进行标注（可选）

使用方法：

文本资源上传：

方式一：直接输入文本
1. 进入"用户上传"页面
2. 选择资源类型为"文本"
3. 选择"直接输入文本"
4. 在文本框中输入文本内容
5. （可选）勾选"上传时进行标注"，填写标注信息
6. 点击"上传并提交AI标注"或"上传并保存标注"

方式二：上传文件
1. 进入"用户上传"页面
2. 选择资源类型为"文本"
3. 选择"上传文件（Word/PDF）"
4. 选择Word文档（.doc, .docx）或PDF（.pdf）文件
5. （可选）勾选"上传时进行标注"，填写标注信息
6. 点击"上传并提交AI标注"或"上传并保存标注"

图像资源上传：
1. 进入"用户上传"页面
2. 选择资源类型为"图像"
3. 选择JPG（.jpg）或PNG（.png）图片文件
4. （可选）勾选"上传时进行标注"，填写标注信息
5. 点击"上传并提交AI标注"或"上传并保存标注"

支持的文件格式：
- 文本类型：Word文档（.doc, .docx）或PDF（.pdf）
- 图像类型：JPG（.jpg）或PNG（.png）
- 资源若无图片，系统会在图片列表中自动生成一条默认图片（uploads/default.jpg）用于展示

注意：
- 系统会自动解析Word和PDF文件的内容，用于AI标注
- 如果用户在上传时提供了标注，会立即保存，同时仍会触发AI标注
- 上传的资源会自动创建标注任务，AI会自动进行标注

5. 标注任务

功能说明：
- 查看和管理标注任务
- 普通用户只能看到自己上传资源的标注任务
- 管理员可以看到所有标注任务（包括爬虫、用户上传、AIGC生成）
- 标注任务中会显示资源内容（文本预览或图片），便于标注

任务状态说明：
- 待标注：任务已创建，AI尚未开始
- AI标注中：AI正在处理资源
- AI标注完成：AI标注结果已保存
- 已完成：人工标注完成（包括上传时自标注或任务页上的人工编辑）

使用方法：
1. 进入"标注任务"页面
2. 使用状态筛选器筛选任务（可选）
3. 查看任务列表，每个任务显示：
   - 资源标题和类型
   - 任务状态
   - 标注方式（AI标注/人工标注）
   - 资源内容预览（文本显示预览，图片显示缩略图）
4. 点击"查看标注"查看现有标注
5. 点击"编辑标注"修改标注（仅在状态不是"AI标注中"时可用）
6. 填写标注信息（实体名称、实体类型、描述、来源等）
7. 保存标注

管理员功能：
- 管理员可以看到所有标注任务
- 对于状态为"已完成"的任务，管理员可以：
  - 审核通过：将标注数据迁移到正式表
  - 驳回：拒绝标注结果

6. 评论功能（AIGC页面）

功能说明：
- 在AIGC页面可以查看和发表评论
- 支持对评论点赞和回复
- 收到点赞或回复会有消息通知

使用方法：
1. 在AIGC页面点击"评论"按钮
2. 查看已有评论
3. 输入评论内容，点击"发布"
4. 点击评论的"点赞"按钮进行点赞
5. 点击"回复"按钮回复评论
6. 查看通知消息

7. 用户设置

修改昵称

1. 点击右上角"设置"按钮
2. 在设置列表中点击"昵称"项
3. 输入新昵称（最多100个字符）
4. 点击"确认修改"

设置个人签名

1. 点击右上角"设置"按钮
2. 在设置列表中点击"个人签名"项
3. 在文本框中输入个人签名（最多500个字符）
4. 可以查看字符计数（显示为"已输入字符数/500"）
5. 点击"确认修改"
6. 修改成功后会自动返回设置列表，显示更新后的个人签名

注意：
- 个人签名为可选功能，不设置时显示"未设置"
- 个人签名最多支持500个字符
- 可以随时修改或清空个人签名

更换头像

方式一：通过设置页面
1. 点击右上角"设置"按钮
2. 在设置列表中点击"更换头像"项
3. 选择操作：
   - 上传新头像：选择图片文件，可以裁剪和调整
   - 使用默认头像：恢复为系统默认头像
4. 确认操作

方式二：直接点击头像
1. 点击页面右上角的用户头像
2. 直接进入头像更换界面
3. 选择操作并确认

修改密码

1. 点击右上角"设置"按钮
2. 在设置列表中点击"修改密码"项
3. 选择验证方式：
   - 原密码验证：输入旧密码
   - 二级密码验证：输入安全问题答案（如果已设置）
4. 输入新密码
5. 确认新密码
6. 点击"确认修改"

更换二级问题

1. 点击右上角"设置"按钮
2. 在设置列表中点击"更换二级问题"项
3. 如果已设置二级问题，需要先验证原答案
4. 输入新问题和新答案
5. 点击"确认设置"或"确认更换"

设置页面说明

设置页面采用列表式布局，包含以下功能项：

1. 账号：仅显示，不可修改（显示您的8-10位数字账号）
2. 昵称：可点击修改，下方显示当前昵称
3. 个人签名：可点击设置，下方显示当前签名（未设置时显示"未设置"）
4. 修改密码：可点击进入密码修改界面
5. 更换二级问题：可点击进入安全问题设置界面
6. 退出登录：红色文字，点击后退出登录
7. 注销账号：红色文字，位于最底部，点击后需要输入密码确认，注销后账号将被永久删除

8. 数据大屏（仅管理员）

功能说明：
- 显示系统使用统计
- 包括访问人次、AIGC使用量等
- 显示7天使用趋势

使用方法：
1. 使用管理员账号登录
2. 点击导航栏的"数据大屏"按钮
3. 查看各项统计数据
4. 点击"刷新"按钮更新数据

统计指标说明：
- 历史访问人次：累计登录次数（每次登录成功记录一次）
- 今日访问人次：今日登录次数
- 历史文字AIGC使用人次：累计文字AIGC对话次数（每次对话记录一次）
- 今日文字AIGC使用人次：今日文字AIGC对话次数
- 历史图片AIGC使用人次：累计图片AIGC对话次数（每次对话记录一次）
- 今日图片AIGC使用人次：今日图片AIGC对话次数
- 历史文字AIGC使用次数：累计用户发送的文字AIGC消息数
- 今日文字AIGC使用次数：今日用户发送的文字AIGC消息数
- 历史图片AIGC使用次数：累计用户发送的图片AIGC消息数
- 今日图片AIGC使用次数：今日用户发送的图片AIGC消息数
- 7天使用趋势：最近7天的使用情况折线图（包括访问人次、文字AIGC次数、图片AIGC次数）

常见问题

Q1: 忘记账号怎么办？

A: 账号是系统自动生成的8-10位数字，如果忘记：
1. 尝试回忆注册时显示的账号
2. 联系管理员协助查找
3. 建议：注册时务必保存好账号信息

Q2: 可以修改账号吗？

A: 不可以。账号一旦生成永久不可修改，这是系统的安全设计。

Q3: 注册时没有保存账号怎么办？

A: 如果注册后没有保存账号：
1. 尝试回忆注册时显示的账号
2. 联系管理员协助查找
3. 如果无法找回，需要重新注册

Q4: 图片无法显示？

A: 可能的原因：
1. 网络连接问题
2. 图片文件不存在
3. 浏览器缓存问题（尝试清除缓存）

Q5: AIGC功能无响应？

A: 可能的原因：
1. AI模型API密钥未配置
2. 网络连接问题
3. 服务器负载过高（稍后重试）

Q6: 上传的资源审核需要多久？

A: 审核时间取决于管理员的工作安排，通常会在1-3个工作日内完成。

Q7: 如何查看我的上传记录？

A: 在"标注任务"页面可以查看您上传资源的标注任务状态。

Q8: 评论通知在哪里查看？

A: 评论通知会在AIGC页面的评论区域显示，有新通知时会有提示。

Q9: 数据大屏不显示？

A: 可能的原因：
1. 您不是管理员账号
2. 浏览器缓存问题（尝试刷新或清除缓存）
3. Java后端服务未正常运行（检查端口8000是否有服务运行）
4. 网络连接问题
5. 如果看到统计API错误，可能是数据库连接问题，请检查数据库服务是否正常运行

Q10: 页面一直加载无法打开？

A: 可能的原因：
1. Java后端服务未启动（需要先启动Java后端服务，端口8000）
2. Python AIGC服务未启动（如果使用AIGC功能，需要启动Python服务，端口7200）
3. 网络连接问题
4. 浏览器缓存问题（尝试清除缓存后重新打开）
5. 如果后端服务未运行，页面会在10秒后显示超时错误提示
6. 检查浏览器控制台是否有错误信息（F12）

Q11: 如何退出登录？

A: 点击右上角"设置"按钮，选择"退出登录"。退出后需要重新登录才能访问系统。

注意事项

账号安全

1. 妥善保管账号：
   - 账号是8-10位数字，请务必保存好
   - 建议记录在安全的地方
   - 不要随意泄露给他人

2. 密码安全：
   - 使用强密码（至少6个字符）
   - 定期修改密码
   - 不要使用过于简单的密码

3. 安全问题：
   - 建议设置安全问题，方便找回密码
   - 安全问题的答案要容易记住但不容易被猜到

使用建议

1. 资源浏览：
   - 使用搜索功能快速找到感兴趣的资源
   - 点击资源卡片查看详细信息

2. AIGC使用：
   - 文字AIGC适合问答和故事生成
   - 图片AIGC适合创作和风格迁移
   - 可以上传图片增强理解

3. 资源上传：
   - 确保上传的资源符合文化资源主题
   - 上传前检查文件格式是否正确
   - 耐心等待审核结果

4. 评论互动：
   - 文明用语，尊重他人
   - 理性讨论，避免争吵
   - 及时查看和回复通知

浏览器兼容性

- 推荐浏览器：
  - Chrome（最新版本）
  - Edge（最新版本）
  - Firefox（最新版本）
  - Safari（最新版本）

- 不推荐：
  - IE浏览器（已停止支持）

系统限制

1. 文件大小：
   - 图片上传建议不超过10MB
   - 文本文件建议不超过5MB

2. 会话数量：
   - 建议定期清理不需要的会话
   - 避免会话数量过多影响性能

3. 评论长度：
   - 评论内容建议不超过500字

技术支持
