# 坐标转地址工具使用说明

## 功能说明

`convert_coordinates_to_address.py` 用于将 `cultural_entities` 表中的 `geo_coordinates` 字段从坐标格式（如 "116.4074,39.9042"）转换为具体地址（如 "北京市东城区..."）。

## 支持的 API

程序支持三种地理编码 API，按优先级使用：

1. **百度地图 API** (推荐)
   - 环境变量：`BAIDU_MAP_API_KEY`
   - 申请地址：https://lbsyun.baidu.com/apiconsole/key

2. **高德地图 API**
   - 环境变量：`AMAP_API_KEY`
   - 申请地址：https://console.amap.com/dev/key/app

3. **腾讯地图 API**
   - 环境变量：`TENCENT_MAP_API_KEY`
   - 申请地址：https://lbs.qq.com/console/mykey.html

## 配置方法

### 1. 申请 API 密钥

选择其中一个地图服务商，注册账号并申请 API 密钥。

### 2. 配置环境变量

在项目根目录的 `.env` 文件中添加以下配置（至少配置一个）：

```env
# 百度地图 API（推荐）
BAIDU_MAP_API_KEY=your_baidu_api_key

# 或高德地图 API
AMAP_API_KEY=your_amap_api_key

# 或腾讯地图 API
TENCENT_MAP_API_KEY=your_tencent_api_key

# 可选：指定优先使用的 API（baidu/amap/tencent）
GEOCODING_API=baidu
```

### 3. 运行程序

```bash
python convert_coordinates_to_address.py
```

## 程序功能

1. **自动识别坐标格式**
   - 支持 "经度,纬度" 格式
   - 支持 "纬度,经度" 格式（自动识别并转换）
   - 支持包含说明文字的格式（如 "91.1172,29.6469 (说明)"）
   - 自动过滤无效坐标（如 "0.0000,0.0000"）

2. **智能地址转换**
   - 使用逆地理编码 API 将坐标转换为详细地址
   - 自动跳过已经是地址格式的记录（包含"省"、"市"、"县"等中文字符）

3. **错误处理**
   - 自动重试不同的 API（如果第一个失败）
   - 记录转换失败和跳过的记录
   - 显示详细的处理进度

4. **API 限流保护**
   - 每次 API 调用后延迟 0.5 秒，避免触发限流

## 注意事项

1. **API 配额限制**：不同地图服务商对免费 API 有调用次数限制，请根据数据量选择合适的服务商。

2. **坐标系统**：程序自动识别坐标格式，但建议使用 WGS84 坐标系统（GPS 坐标）。

3. **无效坐标处理**：程序会自动跳过无效坐标（如 "0.0000,0.0000"）和已经是地址格式的记录。

4. **数据备份**：建议在运行前备份数据库，以防意外情况。

5. **批量处理**：如果数据量很大，程序会自动处理所有符合条件的记录，可能需要较长时间。

## 故障排除

### 问题1：API 调用失败

**原因**：API 密钥无效或配额用完

**解决**：
- 检查 API 密钥是否正确
- 登录地图服务商控制台查看配额使用情况
- 尝试使用其他地图服务商的 API

### 问题2：转换失败

**原因**：坐标无效或不在服务范围内

**解决**：
- 检查坐标是否有效（中国范围内：经度 73-135，纬度 18-54）
- 某些偏远地区可能无法获取详细地址

### 问题3：程序运行缓慢

**原因**：API 调用有延迟限制

**解决**：
- 这是正常现象，程序已设置延迟避免触发限流
- 可以调整 `time.sleep(0.5)` 的值，但不建议设置太小
